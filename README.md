📦 Supply Chain Management Dashboard | Tableau Project
📌 Project Overview

This project presents an interactive Supply Chain Management Dashboard built using Tableau to analyze sales performance, inventory levels, regional trends, and purchase methods.
The dashboard helps stakeholders make data-driven decisions by providing clear KPIs and visual insights across multiple business dimensions.

🎯 Objectives

Monitor Total Sales, YTD, and QTD performance

Analyze Sales Growth trends over time

Track Inventory and Stock Status

Compare Region-wise and Store-wise Sales

Understand Purchase Method preferences

Enable interactive filtering by Year, Region, and Purchase Method

📊 Key KPIs & Metrics

Total Sales: 388M

Total Inventory: 1,905 units

YTD Sales: Year-to-Date performance comparison

QTD Sales: Quarterly sales trends

Sales Growth: Year-wise growth analysis

Stock Status: In-Stock vs Under-Stock

📈 Dashboard Features

✔ Interactive slicers (Year, Region, Purchase Method)
✔ Dynamic KPI cards
✔ Line charts for sales growth
✔ Bar charts for region-wise & method-wise sales
✔ Pie chart for top 5 stores
✔ Inventory stock analysis
